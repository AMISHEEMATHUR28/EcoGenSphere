🌱 EcoGenSphere

EcoGenSphere is a web platform that helps users grow and manage plants using smart and sustainable gardening practices.

🚀 Features

* Garden planning and management
* Crop library with plant information
* Cultivation guides for better growth
* Soil, weather, and environmental insights
* Pest and disease management

 🛠 Tech Stack

* HTML
* CSS
* JavaScript
* PHP

 ▶️ Run Locally

1. Clone the repository
2. Open `index.html` in your browser
   *(or use XAMPP/WAMP for PHP support)*

 📌 About

This project is designed to support beginners and enthusiasts in building and maintaining healthy green spaces at home.
